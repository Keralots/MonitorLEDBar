Home Assistant

Connect to your MQTT broker. The bar then appears in Home Assistant automatically as a dimmable light.

MQTT --

mqtt

With the Mosquitto broker add-on, the host is usually the IP address of your Home Assistant. use a Home Assistant user (or a dedicated login) here. Leave the password empty to keep the saved one. Clearing the username also clears the password.

In Home Assistant

The device shows up under Settings → Devices & services → MQTT with the name set on the Network page. It has a light entity (on/off and brightness) plus WiFi signal and IP address diagnostics. When the bar goes offline Home Assistant marks it unavailable.
